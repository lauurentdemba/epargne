# Objectif : épargne à ton rythme — obtenir l’APK (10 minutes, sans rien installer)
1. Crée un compte gratuit sur github.com, puis un nouveau dépôt (privé si tu veux).
2. Envoie TOUT le contenu de ce dossier dans le dépôt (bouton « Add file > Upload files », y compris le dossier .github).
3. Onglet « Actions » : le workflow « Build APK » se lance seul (≈ 5 min). Sinon : Run workflow.
4. Ouvre l'exécution terminée, section « Artifacts », télécharge epargne-100m-apk (zip), extrais app-debug.apk.
5. Envoie l'APK sur ton téléphone, ouvre-le et autorise « installer des applications inconnues ».
## Changer de téléphone
Réglages > « Sauvegarder / partager » : enregistre le fichier .json (Drive, WhatsApp, e-mail). Sur le nouveau téléphone : installe l'APK, Réglages > « Restaurer depuis un fichier ».
Désinstaller l'application efface les données : sauvegarde avant.
